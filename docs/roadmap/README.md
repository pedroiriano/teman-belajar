# Teman Belajar Roadmap

Direktori ini memuat urutan delivery yang telah disetujui secara produk. Roadmap
tidak menggantikan arsitektur, kontrak, ADR, task specification, atau approval
gate. Sumber kanonis ekspansi setelah TASK-012 adalah:

- `POST-TASK-012-EXPANSION-ROADMAP.md` — TASK-013 sampai TASK-024.

Status `PLANNED` bukan izin untuk mengaktifkan route, menu, API, migrasi, atau
runtime. Implementasi harus memakai satu task branch per bounded task dan
memenuhi dependency serta acceptance criteria task tersebut.
