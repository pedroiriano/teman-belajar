# ADR-001 — Composable LXP + Moodle Learning Engine
**Status:** Accepted

## Context
Kebutuhan mencakup portal/CMS/knowledge modern dan LMS matang.

## Decision
Gunakan custom experience portal dan pertahankan Moodle sebagai authoritative learning engine.

## Consequences
+ Mengurangi reinvention LMS.
+ Portal bebas berkembang.
- Membutuhkan integration layer dan SSO yang disiplin.
